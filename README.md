# Capstone Project

## Overview

This capstone project demonstrates a responsive web application built with HTML, CSS, JavaScript, and Node.js. It showcases AI-assisted software development practices, clean code organization, and a structure that supports future features and deployment.

## Features

- Responsive UI using modern HTML and CSS
- Interactive behavior implemented with JavaScript
- Node.js support for local development and backend logic
- Focus on maintainable code and clear project structure

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the app: `npm start`

> Update these commands if your project uses different scripts.
